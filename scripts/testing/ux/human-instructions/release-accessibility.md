# Release, accessibility, and resilience

- Use Tab, Shift+Tab, Enter, Space, Escape, pointer, and touch; verify visible
  focus, sensible order, labels, disclosure state, and focus restoration.
- With cache disabled and enabled, confirm local JS, CSS, JSON, fonts, and SVGs
  load; check slow loading and repeated disclosure/scroll actions for duplicate
  handlers or unstable controls.
- Inspect Updates XML, canonical metadata, redirects, sitemap policy, glossary
  generation, and representative social cards only when those outputs are in
  scope.
- After deployment, repeat the quick checklist publicly, confirm the approved
  commit and representative HTTP resources, hard-refresh/incognito behavior,
  root-relative links, continuous loading, and console/network cleanliness.
