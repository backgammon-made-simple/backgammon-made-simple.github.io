# Third-Party Notices

Record every third-party dependency or asset redistributed or referenced by this repository.

Current items requiring confirmation before release include:

- Source Sans 3 font files used by the social-card renderer;
- R and Python package dependencies;
- Quarto and browser automation dependencies;
- engine names, output, screenshots, or identifiers used in examples;
- any external icons, screenshots, or board assets.

For each item record:

```text
name
version/source
copyright holder
licence
files/paths
modifications
redistribution notes
```

Do not assume that the website's AGPL or CC BY-SA terms relicense third-party material.
